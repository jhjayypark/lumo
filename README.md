# Lumo

Cambodia's first EV-charging convenience network. Frontend prototype: 8 mobile screens for find-charge-grab-go.

**Stack:** Vite · React 18 · Tailwind 3 · Phosphor Icons · Geist

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
